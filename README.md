## Live Site
Once GitHub Pages is enabled, your site will be available at:  
`https://[your-organization].github.io/[repository-name]/`

## Getting Started with GitHub Pages

1. After creating this repository from the template, go to **Settings → Pages**.
2. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`
3. Click **Save**.
4. Wait 1–2 minutes, then visit the link shown on the Pages settings page.

A starter `index.html` is already included in the root of this repository.
